Why another STIX library? 🤔¶

  • 🌍 One engine, no validation gaps — most STIX libraries are reimplemented per language, so the same document can be valid in one and rejected in another. stixflayer ships a single Rust core into every language, so data validates the same way everywhere.
  • ⚔️ Battle-tested, but faster — built from OASIS's reference implementation, with full parity against the industry-standard validator, at 10–40× the speed.
  • 🧐 Stricter where it matters — rejects empty bundles, invalid vocabulary values, and incorrect SCO UUIDv5 hashes that other validators skip.

Performance 🚀¶

Operation stix2-validator stixflayer speedup
Parse + validate apt1 bundle ~47 ms ~1.6 ms ~30× 🏎️
Parse + validate poisonivy bundle ~99 ms ~2.3 ms ~40× 🏎️
Serialize apt1 bundle ~0.6 ms ~0.06 ms ~10× 🏎️
Serialize poisonivy bundle ~1.0 ms ~0.09 ms ~12× 🏎️

Install ⚡¶

pip install stixflayer

Requires Python 3.11+. Rust users: cargo add stixflayer 🦀 — API docs at docs.rs/stixflayer.
